Getting Started with EBM

Everything you need to begin issuing electronic invoices

What is EBM?

An Electronic Billing Machine (EBM) is a device or software application used to generate fiscal receipts and invoices that are transmitted to RRA in real-time. All businesses registered for VAT in Rwanda are required to use EBM for their transactions. The system ensures tax compliance and provides customers with verifiable proof of purchase.

EBM Types Available

Windows EBM Application

Desktop application for Windows PCs. Suitable for businesses with a fixed point of sale and reliable power supply.

Most Common

Android EBM Application

Mobile application for Android devices. Ideal for businesses on the go, small shops and service providers.

Mobile

Online EBM (Web-based)

Browser-based EBM accessible from any device with internet. No installation required — works on any operating system.

Cloud

VSDC (Virtual EBM)

For businesses with existing invoicing software. Integrates your system directly with RRA through an API.

Developer

Steps to Get Your EBM

  1. 1

    Register for TIN

    If you don't have a TIN, register at MyRRA or visit the nearest RRA office with your ID and business registration documents.

  2. 2

    Apply for EBM

    Submit your EBM application through MyRRA portal or at an RRA office. You will need your TIN, business license and ID.

  3. 3

    Receive your EBM device or credentials

    Depending on the type chosen, you will receive a physical device, download links, or API credentials for VSDC integration.

  4. 4

    Attend training

    RRA provides free training sessions on how to use EBM. Training schedules are available on the RRA website and at local offices.

  5. 5

    Start issuing invoices

    Begin issuing compliant fiscal receipts and invoices. All transactions are transmitted to RRA in real-time.

Purchase Code Verification

Every EBM receipt has a unique Purchase Code that customers can use to verify the transaction. This helps prevent fraud and ensures tax compliance.

01

Receive Receipt

Get a fiscal receipt with a Purchase Code after every transaction

02

Verify Online

Enter the code on RRA website or scan the QR code on the receipt

03

Confirm Valid

System shows transaction details confirming the receipt is genuine

Common Transaction Types

Transaction Description When to Use Status
Sales Invoice Standard sale of goods or services Every customer purchase Required
Credit Note Reduces amount owed by customer Returns, overcharges, corrections Required
Debit Note Increases amount owed by customer Undercharges, additional charges Required
Refund Receipt Documents money returned to customer Full or partial refunds Required
Proforma Invoice Pre-sale quotation Price estimates, not fiscal Optional
Purchase Code Unique verification code per transaction Auto-generated on each receipt Required

Common Issues & Solutions

EBM not connecting to RRA servers

Check your internet connection. Ensure the EBM application has network access. If using a firewall, whitelist RRA server addresses. Try restarting the EBM application.

Receipt not printing

Verify printer is connected and has paper. Check printer drivers are installed. In Windows EBM, go to Settings > Printer Setup and select the correct printer model.

Transaction stuck in pending

Pending transactions are queued when the network is unavailable. They will transmit automatically when connectivity is restored. Do not turn off the device until they are sent.

Need to issue a credit note

Open the original receipt, select "Issue Credit Note," enter the reason and amount. The credit note will reference the original transaction and adjust your tax records.

Software Integration & VSDC

Technical resources for developers integrating with RRA EBM

What is VSDC?

VSDC (Virtual Sales Device Controller) is an API-based integration that allows businesses with existing invoicing or POS software to connect directly to RRA's EBM system. Instead of using a separate EBM device, your software sends transaction data directly to RRA through a secure API. This is ideal for businesses with custom software, ERP systems, or point-of-sale solutions.

Integration Process

1

Request API Access

Apply for VSDC API credentials through MyRRA or by contacting RRA's technical team. You will need your TIN, business details and a description of your software system.

POST /api/v1/vsdc/application
2

Receive Sandbox Credentials

RRA provides test environment credentials including API key, secret, and sandbox server URL. Use these to develop and test your integration without affecting production data.

API_KEY: vsdc_test_xxxxx | SANDBOX_URL: https://sandbox.ebm.rra.gov.rw
3

Develop & Test Integration

Implement the API endpoints for sales, credit notes, debit notes and refunds. Follow the technical specification document for request/response formats, authentication and error handling.

POST /api/v1/sales | POST /api/v1/credit-notes | POST /api/v1/refunds
4

Submit for Certification

Once testing is complete, submit your integration for RRA certification. RRA will review your implementation, verify transaction flows and confirm compliance with fiscal requirements.

Certification review: 5-10 business days
5

Go Live

After certification, receive production API credentials and switch your integration to the production environment. Your software will now transmit transactions to RRA in real-time.

PRODUCTION_URL: https://ebm.rra.gov.rw/api/v1
