# RRA Service Platforms & Login Portals - Complete Guide

## Overview
RRA has multiple distinct platforms for different services. This guide shows the correct platform and login portal for each service.

## Main Login Portals

### 1. MyRRA Portal
**URL:** https://myrra.rra.gov.rw/  
**Purpose:** Taxpayer account management and TIN services

**Login Options:**
- Login with TIN
- VAT Reward Account login
- Create new TIN account
- Get purchase code (for EBM)

**Services:**
- TIN Registration (Create TIN Account)
- EBM Purchase Code requests
- VAT Reward Account access
- Tax account dashboard
- Tax Compliance Certificate (TCC) requests
- Password recovery

### 2. E-Tax Services Portal
**URL:** https://etax.rra.gov.rw/taxPayerLogin  
**Purpose:** Tax filing and payments

**Services:**
- VAT returns filing
- PAYE returns filing
- Income Tax returns
- Excise Duty returns
- Withholding Tax returns
- Tax payments
- View tax obligations

### 3. RLGMS (Local Government Tax System)
**URL:** https://rlgms.rra.gov.rw/login  
**Purpose:** Decentralized local government taxes

**Services:**
- Property taxes
- Local business taxes
- District-level tax management
- Local tax payments

### 4. RRA Staff Portal
**URL:** https://staff.rra.gov.rw/  
**Purpose:** RRA employees only

**Access:** Restricted to RRA staff members

### 5. Data Science Portal
**URL:** https://data.rra.gov.rw/  
**Purpose:** Data analytics and reporting

**Access:** Authorized personnel only

## Common User Scenarios

### "I need to file my VAT return"
→ **Use:** E-Tax Services Portal  
→ **URL:** https://etax.rra.gov.rw/taxPayerLogin

### "I need to register for a TIN"
→ **Use:** MyRRA Portal  
→ **URL:** https://myrra.rra.gov.rw/register  
→ **Action:** Click "Create TIN Account"

### "I need an EBM for my business"
→ **Step 1:** Log in to MyRRA Portal  
→ **Step 2:** Request purchase code  
→ **Step 3:** Buy EBM from authorized supplier  
→ **Step 4:** Register EBM on RRA system

### "I need to pay my property tax"
→ **Use:** RLGMS  
→ **URL:** https://rlgms.rra.gov.rw/login  
→ **Note:** This is for local government taxes, not RRA central taxes

### "I forgot my password"
→ **For E-Tax:** Use password recovery on E-Tax login page
→ **For MyRRA:** Use "Forgot password" link on MyRRA login page
→ **For RLGMS:** Use password recovery on RLGMS login page

## Key Distinctions

### MyRRA vs E-Tax
- **MyRRA** = Account management, TIN registration, purchase codes, VAT rewards
- **E-Tax** = Actual tax filing and payments (VAT, PAYE, Income Tax, etc.)

### Central Taxes vs Local Taxes
- **Central Taxes** (VAT, PAYE, Income Tax) → E-Tax Services
- **Local Taxes** (Property, District taxes) → RLGMS

### EBM Purchase Code
- Requested through **MyRRA Portal** (not a separate EBM portal)
- Protects your TIN from unauthorized EBM registration
- Required before purchasing EBM device
